# AI 学英语小程序 · AI 口语搭子

微信小程序和 Node.js 实时语音后端，支持六个英语练习场景、流式语音、打断、字幕与费用估算。

## 运行

需要 Node.js 22 或更新版本。

```sh
cd AI口语搭子/app
npm ci
cp .env.example .env
# 在 .env 中填写自己的千问百炼配置
npm start
```

电脑调试页：http://127.0.0.1:8788。微信开发者工具导入 `AI口语搭子/app/miniprogram`。

详见 [开发与配置指南](AI口语搭子/app/README.md)。测试：在 app 目录运行 `npm test`。

浏览器版现提供 Vercel WebRTC 接入：Vercel 只转发短时 SDP 握手，音频直接连接百炼。按[部署说明](AI口语搭子/app/docs/Vercel部署.md)设置仓库根目录和环境变量后重新部署。当前代码与本地模拟测试已完成，尚未验证真实云端通话；微信小程序继续使用 Node.js WebSocket 后端。

30 秒产品展示片及可编辑 Remotion 工程在 [showreel/](AI口语搭子/showreel/README.md)。片中对白为脚本演示。

## 项目内容

- `AI口语搭子/app/`：后端、微信客户端、浏览器调试页、配置及自动化测试。
- `AI口语搭子/`：实时对话实现方案、系统提示词、设计参考。
- `AI口语小程序/`：需求文档、交互原型和原型截图。
- `scripts/`、`templates/`：原型与需求文档辅助工具。

打包和版本管理排除密钥、访问口令、个人配置、本地运行数据、依赖和缓存。语音球组件的上游许可证与署名保留在源码中；具体说明见开发指南。
