    连接设置

    API 密钥只放在后端。本地浏览器会自动领取应用访问口令，不需要把百炼密钥填进页面。

    1. 在阿里云百炼控制台切换到北京地域，创建 API Key，确认可使用实时语音模型，并找到对应业务空间 ID。
    2. 将项目的 .env.example 复制为 .env，填写 DASHSCOPE_API_KEY 和 DASHSCOPE_WORKSPACE_ID。
    3. 重新启动后端服务，点击下方“重新检查连接”。微信 AppID 在小程序项目配置中单独填写。
    没有密钥时也可以检查麦克风；页面不会模拟 AI 回复。设置生效后，点击“开始聊天”才会创建模型会话。
