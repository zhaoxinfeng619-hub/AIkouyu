# AI口语搭子 · 微信小程序

原生微信小程序，无构建依赖。实时 PCM 收音、24 kHz 连续播放、字幕、语音打断、静音、计时和费用展示通过本项目后端连接千问；客户端不保存百炼 API Key。

## 导入与连接

1. 在微信开发者工具中导入本目录。`project.config.json` 的 `touristappid` 仅是临时占位；在项目设置中换成你自己的小程序 AppID。
2. 按上级 `app/README.md` 启动后端。默认端口 `8788`。暂时没有百炼账号也能检查页面和设置，首页会提示「服务待配置」，不会假装已接通 AI。
3. 打开小程序「设置」。开发者工具模拟器填 `http://127.0.0.1:8788`；应用访问口令从本机浏览器测试页复制，或使用后端设置的口令。这里不要填写百炼 API Key。
4. 后续申请百炼账号、配置服务器密钥并重启后，测试连接、保存设置，再选择场景开始练习。
5. 手机里的 `127.0.0.1` 指向手机自己。真机请使用手机能访问的 HTTPS 服务域名，并在微信公众平台配置 request 合法域名和对应的 WSS socket 合法域名。本项目的 `urlCheck: false` 仅便利开发者工具本地调试，不替代正式域名配置。
6. 在微信后台填写小程序隐私保护指引，声明录音用途和向模型服务发送音频的处理方式。页面实现了微信隐私授权按钮及麦克风授权，二者通过后才创建语音会话。

## 交互与音频

- 场景：日常闲聊、咖啡点单、旅行出发；难度：慢慢来、有点基础；表达建议：聊时轻提醒、先尽情聊。
- `RecorderManager` 使用 `format: 'PCM'`、16 kHz、单声道、`frameSize: 4` KB（约 128 ms），持续上传录音分帧。静音时停发帧，避免反复启停录音。
- `WebAudioContext` 将 24 kHz PCM16 little-endian 转成浮点数连续调度；处理奇数字节、切片边界。打断时停止所有已调度节点，丢弃旧 response 的迟到音频。`audio.done` 只表示生成完成，最后一个音频节点结束后才发送 `playback.done`。
- 初版优先戴耳机测试。普通录音 + WebAudio 并不自动保证设备级回声消除；外放效果、英语停顿判定、同录同播需要分别在 Android 和 iOS 真机验证。
- 录音上限 10 分钟，达到上限结束本次练习；切后台、系统录音中断、离开页面、断线均清理麦克风、播放器及连接。
- 字幕只在当前页面内存中显示，不持久化到本机；录音临时文件在录音结束后请求删除。后端日志和模型平台的数据处理规则另见服务端说明。
- 本次费用来自后端 `usage`，是估算值，以百炼账单为准。

## 检查

在本目录运行 `node --test tests/*.test.js`。测试覆盖 PCM 字节边界、连续播放、播放完成时机、打断后的迟到音频、URL 校验、未配置/未授权时禁止创建会话、页面离开取消、网络拥塞退出和字幕合并。

微信开发者工具能验证页面编译与逻辑；官方类型说明 PC 平台不支持指定录音采样率。因此模拟器录音不能代表手机音频验收。真实模型音频调用、计费和真机体验须在配置密钥后完成。

## 官方依据

语音动效采用 [Rare UI](https://rareui.com) 的 Fluid Orb，原始 shader 与版权声明见 `utils/voice-orb.js`。本项目添加了微信 Canvas 适配及对话状态、音量联动；小程序设置页可查看并复制来源链接。

- [微信官方 API 类型定义（录音 PCM、分帧、WebAudio 和隐私授权）](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)
- [微信隐私授权开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)

接口契约与后端保持一致：`GET /api/health`、`POST /api/sessions`，再通过短期 ticket 连接同源 WebSocket。后端会验证应用访问口令；千问密钥始终留在服务器。
