# 参考分析计划
本轮原计划：先完成连续帧联系表分析，再开始产品制作。
用户已授权：缺失72张指定联系表时，使用skill包内案例图继续制作约30秒展示片。以下观察只对实际查看的案例图成立，不构造缺失的逐帧证据。

1. **视觉焦点与构图**：比较活动卡中心、卡尺寸与聚焦范围。
2. **推拉摇移与观察范围**：比较手机裁切消失与内容进入更宽的容器。
3. **产品载体变化**：观察同一视频被网页包裹、同一首卡进入卡组。
4. **界面真实操作与响应**：观察导航选中、搜索词进入输入框与结果刷新。
5. **缓动与逐帧速度**：案例图为间隔抽帧，只判断方向与位移趋势，不推断未见帧速度。
6. **上一动作、当前动作、下一动作的重叠**：判断上一卡尚在移动时后续卡与容器是否已可见。
7. **焦点交接与运动匹配**：跟踪同一内容、色彩、裁切与运动轴。
8. **产品信息增量**：单卡扩成库、关键词进入搜索、素材进入发布结果。
9. **停顿与大小节奏**：区分可读结果与载体切换，制作时按实际成片检查。
