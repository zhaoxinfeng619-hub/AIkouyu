# 案例观察与产品应用
已实际查看：naver-phone-to-desktop、naver-single-card-to-deck、naver-video-wraps-into-ui、naver-page-exit-next-phone、naver-nav-to-phone、generated-search-to-payment、generated-group-chat-to-publish。

- 案例7：首张音频卡在增加新卡后仍是集合成员。本片coffee-card贯穿六场景列表、Alex详情、通话角色、结尾六人；身份和图片连续。
- 案例1：同一播放内容被新页面边界包裹。本片Alex场景插画持续存在，详情裁切边界扩大成为通话背景，字幕从现有蓝色开始按钮方向进入。
- 案例8：同一关键词飞入搜索框。本片当前字幕连续收进对话记录的同名行，保留文字、颜色和方向。
- 案例3：选中项收进下一载体。本片语音球模式的选中底板开始移动后，球体与字幕围绕同一角色建立。

上述只复用交接方法；保留产品已有的蓝色、灰底、圆角与六人插画。主要镜头以8帧重叠进入；场景边界保留共享对象。产品操作覆盖不计背景。
